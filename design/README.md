# Material de referência

Esta pasta preserva arquivos que não participam da V1 publicada:

- `experiments/`: implementações anteriores de componentes e helpers.
- `source-assets/clients/`: PNGs originais das fotografias; a página usa as versões otimizadas em `public/assets/clients/`.
- `proposals/`: propostas HTML/CSS e referências visuais.

Os experimentos estão excluídos do TypeScript e podem conter imports históricos
ou dependências removidas. Para retomá-los, adapte-os à arquitetura atual antes
de importá-los em `src/`. Nenhum arquivo desta pasta é copiado para `out/`.
